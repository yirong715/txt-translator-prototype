# 机器翻译 页面需求说明（产品交付版）

> 本文档面向 UI / 前端开发 / 测试团队，描述机器翻译页面的界面组件、交互行为与业务约束。
> 所有元素以标准 UI 组件名称与业务语言描述，不涉及底层代码实现细节。

---

## 一、页面概要

| 项 | 内容 |
|----|------|
| 页面名称 | 机器翻译 |
| 页面类型 | 工具操作页（配置 + 输入 + 翻译执行 + 结果展示 + 敏感词管理弹窗） |
| 主题模式 | 深色（默认）/ 浅色，支持手动切换 |
| 界面语言 | 中文（默认）/ 英文，支持手动切换 |
| 画布尺寸 | 1920 × 1024（固定画布，居中布局） |

### 页面区域结构（自上而下）

1. **顶部导航栏**：品牌标识 + 界面语言切换 + 主题切换 + 用户头像
2. **页头区**：页面标题「机器翻译」+ 副标题 + 分隔装饰线
3. **能力面板**（主操作区，玻璃卡片容器），内含：
   - 配置工具栏：语言对（源/互换/目标）+ 专业领域 + 敏感词按钮 + 翻译按钮
   - 错误提示条（条件显示）
   - 翻译区：原文输入区 | 译文展示区（左右双栏，中间分隔线）
4. **敏感词管理弹窗**（点击敏感词按钮触发，模态浮层）
5. **全局轻提示**（Toast，条件显示）

## 三、业务规则

### 3.1 翻译状态流转

翻译执行存在以下状态，由状态指示器（状态标签）实时反映：

| 状态 | 标签文案 | 触发时机 |
|------|---------|---------|
| 已就绪 | 已就绪 / Ready | 页面初始加载、清空后 |
| 翻译中 | 翻译中 / Translating | 点击翻译按钮后、结果返回前 |
| 已完成 | 已完成 / Done | 翻译成功返回结果 |
| 已拦截 | 已拦截 / Blocked | 前置风控命中敏感词 |
| 请输入内容 | 请输入内容 / Empty | 空内容提交 |

### 3.2 核心业务关联

- **敏感词与翻译风控联动**：敏感词管理弹窗中维护的敏感词列表，直接作为翻译前置风控的判定依据。在弹窗中新增 / 删除 / 编辑敏感词并保存后，后续翻译请求立即按最新列表进行拦截判定。
- **专业领域与术语库联动**：选择不同专业领域会加载对应的领域术语库，影响译文的专业术语准确度。切换领域后若已有译文，将按新领域重新翻译。

### 3.3 专业领域术语库（领域 → 术语对照示例）

| 领域 | 术语对照示例 |
|------|-------------|
| 通用 | 无专属术语 |
| 信息技术 | API → Application Programming Interface；算法 → algorithm；接口 → API endpoint；缓存 → cache |
| 生物医药 | 基因 → gene；疫苗 → vaccine；抗体 → antibody；临床试验 → clinical trial |
| 金融财经 | 对冲 → hedging；市值 → market cap；结算 → settlement；收益率 → yield |
| 法律合同 | 合同 → contract；条款 → clause；违约 → breach；仲裁 → arbitration |

| 操作 | 触发条件 | 行为说明 | 校验 | 反馈 |

### 5.3 翻译操作

| 操作 | 触发条件 | 行为说明 | 校验规则 | 成功反馈 | 失败反馈 |
|------|---------|---------|---------|---------|---------|
| 立即翻译 | 点击翻译按钮（翻译中不可点击） | 校验输入 → 前置风控 → 执行翻译 → 展示结果 | 见下方校验规则 | 译文展示在结果区，状态变「已完成」 | 见下方异常反馈 |
| 清空 | 点击清空按钮 | 清空原文、计数归零、清空译文、隐藏错误提示 | 无 | 无 | 无 |

**立即翻译校验规则：**

| 校验项 | 条件 | 处理 |
|--------|------|------|
| 空内容校验 | 原文去空格后为空 | 提示「请输入要翻译的内容。」，状态「请输入内容」，不发起翻译 |
| 超长校验 | 原文超过 2000 字符 | 提示「文本过长，请拆分后重试。」，不发起翻译 |
| 敏感词风控校验 | 敏感词过滤开启且原文命中敏感词 | 提示「文本包含敏感内容，已拦截，请修改后重试。」+ `***` 掩码，状态「已拦截」，清空结果区 |

### 5.4 译文结果操作

| 操作 | 触发条件 | 行为说明 | 成功反馈 | 失败反馈 |

| 复制译文 | 点击复制按钮（结果区有内容时有效） | 过滤 `***` 脱敏符号后写入剪贴板 | 提示「复制成功」 | 提示「复制失败」 |

## 六、异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户提示 |
|---------|---------|---------|---------|
| 空内容提交 | 点击翻译时原文为空 | 阻止翻译请求，状态置「请输入内容」 | 「请输入要翻译的内容。」 |
| 文本超长 | 原文超过 2000 字符 | 阻止翻译请求 | 「文本过长，请拆分后重试。」 |
| 敏感词命中 | 敏感词过滤开启且原文包含敏感词 | 拦截翻译请求，清空结果区，状态置「已拦截」 | 「文本包含敏感内容，已拦截，请修改后重试。」（命中词以 `***` 掩码显示） |
| 字数预警 | 输入字数 > 1800 且 < 2000 | 字数计数变黄色 | 无（视觉提示） |
| 字数超限 | 输入字数 ≥ 2000 | 字数计数变红色，输入框禁止继续输入 | 无（视觉提示） |
| 翻译中重复点击 | 翻译执行期间再次点击翻译按钮 | 按钮禁用，忽略重复点击 | 无 |
| 复制失败 | 剪贴板写入失败 | 降级使用兼容方式复制；仍失败则提示 | 「复制失败」 |
| 语音朗读不可用 | 浏览器不支持语音合成 | 不执行朗读 | 「浏览器不支持语音朗读」 |
| 敏感词重复 | 新增/编辑的敏感词已存在 | 阻止写入 | 「该敏感词已存在」 |

## 八、待补充事项

以下内容在当前原型中未体现，需产品/业务方确认后补充：

1. **角色权限**：页面访问是否需要特定角色/权限
2. **入口与路由**：从哪个菜单/页面进入，路由级可见性条件
3. **网络异常处理**：翻译请求网络失败时的提示与恢复策略（如「网络连接失败，请检查网络设置」，保留输入内容）
4. **后置风控**：译文输出前的二次敏感词检测与熔断逻辑
5. **多引擎降级**：冷门语种置信度低时的统计机器翻译兜底
6. **并发与请求取消**：连续翻译请求的防抖与取消机制
7. **敏感词分级处置**：当前原型所有命中均按一级拦截处理；业务上是否需要二级中危（降级改写）、三级低危（轻度润色）的分级策略
